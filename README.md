# Sfiord Telegram Support Search — n8n

یک Workflow سبک و بدون هوش مصنوعی که پیام کاربر را از تلگرام دریافت می‌کند، داده‌های صفحه `https://sfiord.com/sup/` را می‌خواند و مرتبط‌ترین عنوان‌ها و لینک‌ها را برمی‌گرداند.

## ویژگی‌ها

- بدون Gemini، OpenAI یا هر API هوش مصنوعی
- بدون دیتابیس
- دریافت مستقیم اطلاعات از همان صفحه پشتیبانی
- جست‌وجوی فارسی با یکسان‌سازی حروف `ی` و `ک`
- نمایش حداکثر پنج نتیجه مرتبط
- دریافت نسخه فعلی صفحه در هر درخواست

## راه‌اندازی

1. فایل `sfiord-telegram-support.workflow.json` را از بخش **Import from File** وارد n8n کنید.
2. در BotFather یک ربات بسازید و توکن آن را دریافت کنید.
3. در n8n یک Credential از نوع **Telegram API** بسازید.
4. Credential را به `Telegram Trigger` و `Send Telegram Results` متصل کنید.
5. Workflow را Save و سپس Activate کنید.

## نمونه

کاربر می‌فرستد: `چطور دوربین را روی آیفون نصب کنم؟`

ربات مرتبط‌ترین عنوان‌ها و لینک‌های موجود در صفحه پشتیبانی را نمایش می‌دهد.

## محدودیت

این نسخه جواب جدید تولید نمی‌کند و فقط میان اطلاعات موجود در همان صفحه جست‌وجو می‌کند. چون صفحه اصلی بیشتر یک فهرست راهنماست، خروجی عمدتاً شامل عنوان و لینک موضوعات مرتبط است.

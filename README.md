# Sfiord Telegram Support Bot (n8n)

این مخزن شامل یک Workflow آماده n8n است که سؤال کاربر را از تلگرام می‌گیرد، صفحه پشتیبانی اسفیورد را بررسی می‌کند، حداکثر سه مقاله مرتبط را می‌خواند و با Gemini یک پاسخ فارسی مبتنی بر همان منابع تولید می‌کند.

## معماری

1. دریافت پیام با Telegram Trigger
2. خواندن `https://sfiord.com/sup/`
3. استخراج عنوان و لینک مقالات پشتیبانی
4. انتخاب مقاله‌های مرتبط با Gemini
5. دریافت محتوای مقاله‌ها و ساخت پاسخ مستند
6. ارسال جواب به همان گفت‌وگوی تلگرام

## راه‌اندازی

1. فایل `sfiord-telegram-rag.workflow.json` را در n8n از بخش **Import from File** وارد کنید.
2. در BotFather یک ربات بسازید و توکن آن را بگیرید.
3. در n8n یک Credential از نوع **Telegram API** بسازید و به دو نود زیر متصل کنید:
   - `Telegram Trigger`
   - `Send Telegram Answer`
4. از Google AI Studio یک Gemini API key بگیرید.
5. در n8n یک Credential از نوع **Header Auth** بسازید:
   - Name: `x-goog-api-key`
   - Value: کلید Gemini شما
6. همین Credential را به دو نود زیر متصل کنید:
   - `Gemini Select Articles`
   - `Gemini Answer`
7. Workflow را Save و سپس Activate کنید.
8. در تلگرام به ربات پیام متنی بدهید؛ نمونه: `چطور دوربین را به گوشی آیفون وصل کنم؟`

## نکات مهم

- n8n باید از اینترنت و HTTPS عمومی در دسترس باشد تا Telegram Trigger کار کند.
- هیچ توکن یا API key را داخل فایل Workflow یا GitHub قرار ندهید؛ فقط از Credentials خود n8n استفاده کنید.
- پاسخ‌ها فقط بر اساس صفحات انتخاب‌شده از دامنه `sfiord.com` تولید می‌شوند.
- هر سؤال در لحظه سایت را می‌خواند؛ بنابراین پاسخ‌ها با تغییر محتوای سایت به‌روز می‌مانند، اما چند درخواست HTTP برای هر پیام مصرف می‌شود.
- قبل از استفاده تجاری، مجوز استفاده و شرایط سایت را بررسی کنید و نرخ درخواست‌ها را محدود نگه دارید.

## عیب‌یابی سریع

- اگر Telegram Trigger اجرا نشد، آدرس عمومی n8n و HTTPS را بررسی کنید.
- اگر Gemini خطای 401 یا 403 داد، نام Header باید دقیقاً `x-goog-api-key` باشد.
- اگر پاسخ خالی بود، خروجی نودهای `Load Support Index` و `Load Selected Articles` را بررسی کنید؛ سایت ممکن است ساختار HTML یا سیاست دسترسی خود را تغییر داده باشد.
